# Watermelon UI

**Link:** https://ui.watermelon.sh/
**Category:** UI Component Libraries

## What it is

Watermelon UI is an open-source component registry offering production-ready, copy-pasteable React components, dashboards, and UI blocks — built with React 19, Tailwind CSS v4, Radix UI, and Framer Motion.

## Who it's for

Developers who want high-quality, ready-made UI pieces they can drop straight into a codebase without pulling in a monolithic component library.

## Key Features

- 260+ components: buttons, inputs, cards, accordions, modals, charts, dashboards, and more
- Copy-paste architecture — components are added directly into your project, giving full ownership and control
- shadcn/ui compatible — works with the shadcn CLI and registry protocol (e.g. `npx shadcn@latest add "https://registry.watermelon.sh/button.json"`)
- Fully typed and customizable since components live in your own codebase
- 100% free and open source

## Access

Web app / component registry at [ui.watermelon.sh](https://ui.watermelon.sh/).
