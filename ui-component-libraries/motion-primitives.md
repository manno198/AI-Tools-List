# Motion Primitives

**Link:** https://motion-primitives.com/
**Category:** UI Component Libraries

## What it is

Motion-Primitives is an open-source UI kit for building beautiful, animated interfaces faster. It's built for React, Next.js, and Tailwind CSS, using Framer Motion for animations.

## Who it's for

Frontend developers who want polished, professional animations and micro-interactions in React apps without needing deep animation expertise.

## Key Features

- 50+ (growing toward 100+) responsive, animated components: buttons, cards, modals, page transitions, scroll-triggered animations, progressive blurs, animated backgrounds, and more
- Built with Framer Motion + Tailwind CSS, focused on performance and accessibility
- Install via `npx` or the shadcn/ui CLI — add components individually to keep bundle size small
- Free core library under MIT license, with a Pro tier for advanced components and templates
- Positioned as an open-source alternative to Aceternity UI and Magic UI

## Access

Web app / component registry at [motion-primitives.com](https://motion-primitives.com/).
