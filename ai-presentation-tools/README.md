# AI Presentation Tools

Tools for generating, designing, and collaborating on AI assisted presentations.

| Tool | Description |
|------|-------------|
| [Beautiful.ai](beautiful-ai.md) | Presentation platform with AI guided outlines and automatically adapting slide layouts |
| [Pitch](pitch.md) | Collaborative presentation workspace with AI tools, templates, and sharing features |
| [Plus AI](plus-ai.md) | AI presentation add-on for creating and editing decks in Google Slides and PowerPoint |
| [PopAi](popai.md) | AI presentation maker for generating and refining slide decks from prompts and source material |
| [Slidesgo](slidesgo.md) | AI presentation maker that creates styled decks and exports to PowerPoint or Google Slides |
| [Tome AI](tome-ai.md) | AI presentation and document conversion service at tomeapp.ai, including editable PPTX export |
