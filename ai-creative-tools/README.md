# AI Creative Tools

AI workspaces for research, image and video creation, editing, and related creative workflows.

| Tool | Description |
|------|-------------|
| [Krea](krea.md) | Creative suite for generating and editing images, video, and 3D assets, with real-time tools and upscaling |
| [OpenArt](openart.md) | AI media creation workspace for images, video, audio, characters, and story production |
| [YouMind](youmind.md) | Learning and creative workspace that turns saved research and ideas into writing, slides, images, video, and webpages |
