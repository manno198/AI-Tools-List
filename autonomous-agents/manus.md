# Manus

**Link:** https://manus.im/
**Category:** Autonomous Agents → General-Purpose

## What it is

Manus is a general-purpose autonomous AI agent developed by Butterfly Effect. Rather than just responding to prompts like a conversational AI, Manus plans, executes, and delivers results for complex, multi-step tasks end-to-end — bridging the gap between "mind" (reasoning) and "hand" (execution). It scored ahead of leading models on the GAIA benchmark for real-world tool use and task automation.

## Who it's for

Creators, designers, developers, teams, and startups who want AI to independently handle multi-step work rather than just assist with individual tasks.

## Key Features

- Creates deliverables directly: slides (PPTX), documents (PDF), websites, spreadsheets, images, and more
- Browser operator for automated web interactions
- "Wide Research" for autonomous research tasks
- Integrations: Mail Manus (email), Slack connectivity, API access for developers
- Available as web app, mobile app, desktop app, and browser integration
- Free tier plus team plans with SSO for enterprise use
