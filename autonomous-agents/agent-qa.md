# agent-qa

**Link:** https://vostride.com
**Category:** Autonomous Agents → Application Testing

## What it is

agent-qa is an application testing agent from vostride. It explores web and mobile apps through CLI or MCP workflows, records test evidence, and uses persistent memory and validated self-improvement to reuse testing experience across runs.

## Who it's for

Developers and QA teams who want agent-driven app exploration, regression checks, and evidence they can review.

## Key Features

- Web and mobile app testing through a CLI and MCP server
- memidex persistent memory for reusable testing knowledge
- Validated self-improvement that evaluates proposed changes before promotion
- Screenshots, logs, and structured findings for reviewing test outcomes

## Access

Requires Node.js 24+, a configured model provider, and the browser or device environment for the target app. The local package is free; model usage and optional external services may cost extra. License: FSL-1.1-ALv2.

See the [quickstart](https://vostride.com/docs/agent-qa/quickstart), [MCP setup](https://vostride.com/docs/agent-qa/mcp), and [source repository](https://github.com/vostride/agent-qa).
