# AI Video Tools

AI powered tools for generating, editing, and producing video.

| Tool | Description |
|------|-------------|
| [Descript](descript.md) | AI video and podcast editor with transcript-based editing, recording, captions, and audio cleanup |
| [InVideo](invideo.md) | Prompt and script to video platform that assembles scenes, visuals, narration, music, and edits |
| [Kling AI](kling-ai.md) | Generates and edits video and images from text or references, with motion and audio controls |
| [Luma AI](luma-ai.md) | Dream Machine creates and edits images and videos from prompts and visual references |
| [Pika](pika.md) | AI creative platform for generating and editing video, images, and audio |
| [Runway](runway.md) | Generative video workspace for text, image, and video creation plus AI editing tools |
