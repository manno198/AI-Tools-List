# Haikei

**Link:** https://haikei.app/
**Category:** Design Asset Generators

## What it is

Haikei is a web app that generates unique SVG design assets through a collection of customizable generators — "a web app to generate stunning visual content, ready to use with your design tools and workflow."

## Who it's for

UI designers, presentation creators, bloggers, and social media content producers — both professionals and hobbyists, thanks to free, no-signup access.

## Key Features

- 15+ generators: waves, blobs, grids, gradients, geometric shapes, and more
- Adjustable parameters, brand color integration, and various canvas sizes
- Exports in PNG and SVG, compatible with design tools and codebases
- "Dice button" randomization for instant new variations
- Pre-sized templates for common formats across different mediums

## Access

Free, no-signup web app at [haikei.app](https://haikei.app/).
